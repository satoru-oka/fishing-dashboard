# samples — 設計確認用プロトタイプ

深掘り分析ダッシュボード（issue #65）の**モックデータ・プロトタイプ**。単一HTMLで、deck.gl と Plotly を CDN から読み込む。**設計確認用**であり本番コードではない（本番は Vite/React SPA、`src/`）。配色・地図は `src/theme.ts` / `src/components/Map3D.tsx` に準拠。

## 見方
- 各 `.html` を**ダウンロードしてブラウザで開く**（deck.gl の WebGL＋CARTO タイル＋CDN を使うため、埋め込みプレビューでは表示されないことがある）。
- データは決定論的なモック（固定シード）。実データではない。

## ファイル
- `deep-dive-dashboard.html` … メイン画面。① 立体棒マップ、② 釣果推移、③ 魚種内訳＋ランキング、④ サイズ分布、⑤ 環境×ヒット率（潮位/水温帯 切替）、⑥ ルアー/餌 効果。①③④⑤⑥ はクリックでクロスフィルタ（AND 合成）。期間スライダーは再生2方式（積み上げ／一定幅ウィンドウ）、上部にアクティブフィルタ・バー。
- `correlation-explorer-and-table.html` … 別モード。相関エクスプローラ（X/Y軸・効果量r/CI/n・総当たりヒートマップ・データ充足ゲート・層別・昇格ボタン）＋ソート可能な釣場別表。

詳細仕様は `../deep-dive-dashboard-spec.md` を参照。
