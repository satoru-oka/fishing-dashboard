# 深掘り分析ダッシュボード 確定仕様（issue #65）

本ドキュメントは深掘り画面の設計を確定させた作業メモ。`docs/deep-dive-dashboard-draft.md` の後継であり、`docs/design-references.md`（根拠・統計の作法）と対になる。プロトタイプは `docs/samples/`。

## 0. 前提・スコープ
- **全魚種対応**の分析基盤。シーバス（多摩川・汽水）は現在の worked example。
- データモデルは **条件（環境）× 行動（選択）→ 結果（釣果）**。
- 統計はサーバ側（FastAPI / pandas・scipy・statsmodels）、ダッシュボードは**可視化に専念**（#40 の方針）。

## 1. 画面構成
サイト本体（`App.tsx`）に準拠：
`Header → アクティブフィルタ・バー → KpiStrip(5) → [① Map | フィルタパネル(340)] → 期間スライダー → ChartsGrid(②〜⑥) → footer`
- ChartsGrid はサイトと同じ **md=2列 / xl=3列** のレスポンシブ全幅グリッド。② Trend のみ広い画面で2列ぶん。
- **個人/公開ビュー切替**：**既定は公開ビュー**（匿名 `public_catches`／認証不要で即・意味ある初期表示）。個人ビュー（JWT）は **Header 右上のグローバルトグル**（RESET / CSV ボタン群の並び）で切替。視点全体を切り替えるグローバル操作なので最上段に置く（#40 の方針／design-references 決定D）。

## 2. パネル仕様
- **① Map（deck.gl ColumnLayer）**：CARTO Dark/Voyager ベースマップ上に立体棒。**高さ＝釣果数 / 色＝平均体長**（coral→sun→gold）。`radius:600 / elevationScale:200 / pitch:45`、立ち上がりアニメ、左下に凡例、右下にスタイル切替、ホバーで釣果/平均/最大。棒クリックで釣場を絞り込み。`src/components/Map3D.tsx` 準拠。
- **② Trend**：月別釣果（左軸・棒）＋水温（右軸・線）＋水位（相対・線のみ、軸目盛りは非表示）＋放水イベント縦線。軸は**単位のみ**（尾・℃）を目盛りに付け、名前は凡例へ。線のマーカーは視認性重視で大きめ＋縁取り。
- **③ Species**：ドーナツ＋余白に**色一致の魚種ランキング**（上位6＋その他）。スライス/行クリックで魚種を絞り込み。
- **④ Size**：5cm刻みヒストグラム。**バークリックでそのサイズ帯に絞り込み**（選択帯をハイライト、全帯は残す）。
- **⑤ Environment**：環境×ヒット率（尾/釣行）。右上に軸セレクタ。**海/汽水＝{潮位フェーズ, 水温帯}**、**淡水＝{水温帯, 水位帯}（既定=水温帯）**。水位帯は多摩川の放水・増水がヒットに効く worked example に対応（`water_level` 由来）。潮回り系は海/汽水限定のまま。**バークリックでそのバケツに絞り込み**。
- **⑥ Method**：ルアー/餌の釣果数ランキング。**バークリックでそのルアー/餌に絞り込み**（選択をハイライト、全体は残す）。

## 3. インタラクション
- **クロスフィルタ**：① 釣場 / ③ 魚種 / ④ サイズ帯 / ⑤ 環境バケツ / ⑥ ルアー のクリックは全パネル連動。複数条件は **AND** で合成。各「選択元」パネルは自分の次元を除いて全選択肢を表示し、選択をハイライト。
- **アクティブフィルタ・バー**：現在の全条件（モード/期間/釣場/魚種/ルアー/サイズ/環境/各チップ）をチップ表示。`×` で個別解除、`すべて解除`で全消去。
- **フィルタパネル**：モード（全/海/汽水/淡水）、時間帯（定義をキャプション＆ホバーで明示）、潮位フェーズ（上げ3分/上げ7分/…）、潮汐（大潮/中潮/…）、天気、ベイト、濁り。
- **期間スライダー**（Map＋フィルタの下／参考サイト準拠）：2ハンドルのレンジ。**再生**ボタンは2方式（**積み上げ式**＝終了端が伸びる / **一定幅ウィンドウ**＝区間が流れる）。**期間リセット**で全期間に戻す。

## 4. データ充足ゲート
- 釣行 n が閾値未満の枠は「データ収集中（n=… / 必要 …）」を表示し、ノイズ提示を避ける。全要素共通のルール。

## 5. 別モード：相関エクスプローラ ＋ ソート可能な表
- **相関エクスプローラ（探索専用）**：X/Y 軸セレクタ、手法の自動判定、散布図＋回帰線、**効果量 r・95%CI・n**（p値ではなく効果量と区間で判断）、層別（季節/釣場の色分け）、**総当たり相関ヒートマップ**（n 不足セルは空欄、セルごとに文字色を切替えて可読性確保）、**データ充足ゲート**、**昇格ボタン**（手動）。
- **新規変数の追加**：#40 の **jsonb 実験層＋変数レジストリ**で新しい因子を追加 → エクスプローラの選択軸に出現 → 効くと確証が取れたら**手動でパネル/フィルタへ昇格**。
- **天気・潮汐（種類）をここに置く理由**：信号が弱い/未確証/交絡しやすく、まだ確証がないため。強い変数（潮の動き・水温・ベイト）は直接パネル化してよい。
- **ソート可能な表**：釣場別サマリ（釣行/総釣果/尾per釣行/平均体長/最大）。列見出しクリックで並べ替え。「釣果×平均体長」の精読はこの表＋地図の立体棒で代替し、専用パネルは増やさない。

## 6. 配色・タイポ
- `src/theme.ts` の東京湾サンセット。背景 `#0a1428`、カード `#0f1d33`、foam 文字、coral/sun/gold/sky アクセント。
- eyebrow＝明朝（字間広め）、見出し＝セリフ、本文＝sans、数値＝mono。
- 薄い白字の明度は読みやすさ優先で引き上げ（foam-dim/sky/sky-dim を明るめに）。
